# 🩺 Pathology Lab Management Software

A modern standalone **Pathology Lab Management Software** built using **Electron.js**. The software helps pathology laboratories manage patients, tests, reports, billing, and daily operations through an easy-to-use desktop application.

## 📸 Dashboard Preview

🌐 Live Demo (UI)

https://gitrajpath.vercel.app/pages/dashboard.html

## ✨ Features

- 🏥 Patient Registration
- 🧪 Test Management
- 📄 Report Generation
- 💰 Billing & Payments
- 📊 Dashboard Analytics
- 👨‍⚕️ Doctor Management
- 🧾 Invoice Printing
- 🔍 Patient Search
- 📅 Appointment Tracking
- 💾 Local Data Storage
- 🖥️ Desktop Application (Electron)
- 🔒 Secure Offline Access

## 📦 Installation

Clone the repository

```bash
git clone https://github.com/yourusername/pathology-lab-software.git

Go to project folder

```bash
cd pathology-lab-software
```

Install dependencies

```bash
npm install
```

Run the application

```bash
npm start
```
